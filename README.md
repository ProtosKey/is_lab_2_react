# is_Lab_2_react

React-клиент для бэкенда лабораторная работа №2: управление городами, справочниками, импорт объектов из файла и история операций.

## Возможности

* **Таблица городов:** пагинация, фильтрация по подстроке (строковые колонки) и сортировка по любой колонке.
* **Карточка города:** создание, редактирование и удаление; координаты и губернатор — выбор из справочника или инлайн-создание.
* **Справочники:** координаты и губернаторы; при удалении связанного объекта указывается замена (города переподвязываются).
* **Импорт:** загрузка JSON-файла через веб-интерфейс; импорт атомарен — при ошибке ни один объект не создаётся, ошибка попадает в историю.
* **История операций:** обычный пользователь видит свои операции, администратор — все (статус, число объектов, причина ошибки, файл).
* **Специальные операции** (только администратор): удаление города по климату, подсчёт по высоте, поиск по подстроке, переселения населения.
* **Права:** просмотр — всем пользователям; изменение и удаление — только своих объектов (администратор — любых).

## Технологический стек

* **UI:** `React 18`, `React Router 6`, `Redux Toolkit`
* **Сеть:** `axios`, `withCredentials`
* **Стилизация:** `src/style/main.css`

## Структура

* `src/controllers`: axios-контроллеры по доменам (`api` - базовый инстанс, `auth`, `cities`, `coordinates`, `governors`, `special`, `importApi`, `operations`)
* `src/store`: Redux store и слайсы (`authSlice`, `citiesSlice`, `listSlices`)
* `src/pages`: страницы (логин/регистрация, города, справочники, импорт, история, спецоперации)
* `src/components`: переиспользуемые компоненты (шапка, таблица городов, форма города)
* `src/utils`: enum'ы бэкенда, хелперы ошибок/дат, хук авторизации `useRequireAuth`

## Запуск
1. Запустить бэкенд (проект `is_lab_2`): поднять `docker compose up -d` и задеплоить WAR на Payara (`http://localhost:PORT/is_lab_2/api`).
2. `npm install` - установятся все библиотеки
3. `npm start` - откроется `http://localhost:3000`

Первый зарегистрированный пользователь получает роль администратора.
